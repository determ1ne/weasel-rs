# 小狼毫RS 设置

独立的 Windows Slint 应用。按主配置及主题 richschema 生成布尔、枚举、文本设置项，
支持继承及用户覆盖保存，保留未识别字段。默认值来自程序配置，用户覆盖来自
weasel.custom.json。语法错误时禁止编辑，外部修改会阻止保存。

保存使用同目录临时文件替换；外部修改检测为保存前的乐观检查，不是跨程序文件锁。
目前关闭窗口会放弃未保存修改。“仅保存”只写入配置；“保存并应用”在保存成功后
向 broker 异步发送重启服务请求，broker 不在运行或发送失败时提示配置已保存但未应用。
请求发送成功不代表重启已完成。新增模块描述仍需重新打开设置加载；尚未加入安装包。

构建：`cargo build -p weasel-settings`。
启动：`cargo run -p weasel-settings`。

采用 Winit 窗口后端和 Skia 默认渲染。等待原生窗口就绪后设置材质，
Windows 11 22H2 及以上请求系统 Mica 背景，
旧系统或材质初始化失败时使用不透明背景。
路径遵循 common 的规则：开发目录 `.dev` 模式使用相邻 `user-data`，
其余使用 `%APPDATA%\Weasel-RS\Rime`。

## 主题描述与保存路径

原生 ABC、Eleven 的描述由构建脚本打包为 `themes/weasel_theme_<id>.settings.json`，
随对应主题安装；缺失时使用设置程序内嵌的描述。WASM 的默认配置和 richschema
打包到模块的 `weasel.settings` custom section，无需为读取描述实例化模块。

主题字段仍保存到 `weasel.custom.json`，而非另建主题配置文件：

- 原生主题：`themeSettings.<id>`。
- WASM：`themeSettings.wasm.modules.<id>.config`。
- 模块选择与路径：`themeSettings.wasm`。

自动发现程序目录 `theme-wasm`、用户数据目录及配置中指定的本地 `file`。
默认模块查找顺序与 renderer 一致：程序目录优先，再找用户目录。
新增 WASM 可随文件携带描述；无描述时提供 JSON 编辑。配置和描述仅在启动时加载，
不监控文件、不提供刷新按钮；新增模块或修改描述后需要重新打开设置。
界面采用单页分区：常规设置始终显示，主题配置随当前选择动态显示，
WASM 只显示当前模块的配置。切换主题保留各分区的未保存编辑。

应用专属设置采用可展开列表，可添加程序文件名并编辑中英文默认状态和内联预编辑。
每个开关可单独恢复继承；整项清除只删除用户覆盖，安装配置中的条目仍保留。
应用项最多 256 个；添加时拒绝路径、非法文件名和重复项。未识别字段不会因编辑开关被删除。

## 安全边界

- 不加载主题 DLL、不执行 WASM，不执行描述里的脚本或命令，不联网解析引用。
- 仅允许本地普通文件，拒绝 UNC/设备路径；目录扫描非递归，每目录最多 512 项、最多 32 个 WASM 主题。
- 描述最多 1 MiB，模块最多 32 MiB，每次目录加载总读取预算 64 MiB。
- JSON 深度最多 32，节点最多 8192，单对象最多 512 字段；表单最多 256 项、深度 16。
- schema 只接受受支持的关键词和本地引用；拒绝引用循环及外部引用，限制正则大小和验证工作量。
- 保存前验证已编辑分组，保留未识别配置；检测外部修改后拒绝覆盖。

上述限制针对设置描述读取和表单生成，不替代 renderer 的 WASM 运行时安全限制。
